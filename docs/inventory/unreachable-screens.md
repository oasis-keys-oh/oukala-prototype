# Unreachable screens (CL-41)

Inventory for backlog item CL-41. Decision adopted 2026-10-19: unreachable screens are **hidden, never deleted**. A hidden screen keeps its id, its render function and every saved link: it still opens by URL (`#<id>`), from builder-mode search and from the Administration card "Hidden screens", where an administrator can unhide it. It carries no status or priority.

Generated by `node tools/lint/reach.js build_out --write` on 2026-10-20. Every count is a **prototype fact** for the build it was run on.

## How reachability is computed

| Path | Counts when | Screens |
|---|---|---|
| Menu | the screen has an entry in a visible menu group (`NAVX.map`, full menu) | 132 |
| Family | it is a view of a folded family (`R15.hidden` with a family or an alias), opened by the family's view switcher | 57 |
| Link | another screen links to it on its first view (`data-go`, `data-nav`, `data-link="screen:id"`), or another source file calls `go("id")` or renders `data-go` or `data-nav` for it (`SCRMAP_DATA` nv) | 188 |
| Tour | a Showroom beat opens it (`SHOW.demos`, beat `go`) | 37 |
| Search | the global search lists it; not enough on its own, because search lists every screen that is not hidden | not counted |

A screen with none of the first four paths is unreachable: 1 of 196 registered screens.

A screen that later gets a menu entry or a link should be removed from `HIDE.LIST` when this inventory is regenerated.
