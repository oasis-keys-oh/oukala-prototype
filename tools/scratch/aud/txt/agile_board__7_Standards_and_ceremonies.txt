Story pointing standard
Relative size, not hours. One scale for every team so work can be compared and rolled up
POINTS	REFERENCE STORY	WHAT IT MEANS
1	Change a label on the editor toolbar	Known change, one place, no risk. Under half a day.
2	Add a field to the audit export	Small change in two places; tests exist.
3	Add keyboard shortcut for save in the editor	Clear but touches several parts; one day of work.
5	Show cross references in the compare panel	Some design choices and test work; two to three days.
8	Resume an interrupted publishing job	Real complexity or a new integration; the upper limit for one sprint item.
13	Rebuild the redline engine on the new index	Too big. Split it before it enters a sprint.
21	Replace the editor save architecture	Epic-sized. Never plan it; break it into features and stories.
Points measure effort, complexity and uncertainty together.
Use the Fibonacci scale: 1, 2, 3, 5, 8, 13, 21. Compare to a reference story, never to hours.
Anything above 8 is split before the sprint. A spike gets a time box, not a size.
Everyone votes together in planning poker, then discusses the highest and lowest vote.
Re-estimate only when new facts appear, not when work is late.

SAFe
Definition of ready and done
The two checklists every story passes through
DEFINITION OF READY
A named product owner wrote it as a user story with a clear benefit
At least two acceptance criteria in plain Given, When, Then form
Estimated by the team, 8 points or fewer
Dependencies named and not blocked
Test approach noted (automated, manual or both)
Design or mock-up attached where the screen changes
DEFINITION OF DONE
Code reviewed and pull request merged
Automated tests written and passing
Manual tests passed where the story changes behavior
Every acceptance criterion demonstrated to the product owner
Accessibility, security and performance checks passed
Documentation and release notes updated
Deployed to the test environment through the pipeline

The sprint board enforces the definition of done: a story cannot move to Done while its pull request is open, a criterion is unmet or a test is failing.
