How a configuration item is created and kept true
Each step is a person, an AI agent, an automatic action or an approval gate. Select a step to see who owns it and how fast it should be. Aligned to ITIL 5, CSDM 5.
Add a step
Open in Workflow designer
AUTOMATIC
Discover
Connected tools (Orion, Azure, vCenter, Intune, Entra, ServiceNow) report what exists. Manual entry is the fallback for things no tool sees.
AUTOMATIC
Identify and reconcile
Identification rules decide if a record is a CI we know; source precedence decides whose value wins for each attribute.
AI AGENT
Assign accountability
Every CI needs a named owner and a support group. The Steward Agent proposes them from teams and past tickets.
PERSON
Link to a service
Each CI is tied to the services it supports so impact analysis can reach the business.
APPROVAL GATE
Audit and attest
Completeness, correctness and compliance rules run nightly; owners attest each quarter.
APPROVAL GATE
Retire
A what-if check shows what depends on the CI before it is retired.
