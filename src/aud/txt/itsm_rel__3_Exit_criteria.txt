Release management process
Each step is a person, an AI agent, an automatic action or an approval gate. Select a step to see who owns it and how fast it should be. Aligned to ITIL 5, DORA metrics.
Add a step
Open in Workflow designer
PERSON
Plan the release
Scope features, set the date, check the calendar for clashes.
AUTOMATIC
Generate readiness tasks
The standard checklist creates child tasks with owners, due dates and gates.
AI AGENT
Build and test
Pipeline builds; Test Agent runs the suite; QA and editors run UAT.
AUTOMATIC
Evaluate exit criteria
Ten criteria are scored automatically from tests, pull requests and defects.
APPROVAL GATE
Security review and CAB
Security signs off the scan; the change advisory board approves the change record.
APPROVAL GATE
Training, communications and OCM approved
Training approved, Communications team approves the package, OCM plan implemented.
APPROVAL GATE
Go or no-go
A named person decides from the evidence. Hard clashes block go.
AUTOMATIC
Deploy through the pipeline
The deployment runs in the approved window with rollback ready.
PERSON
Post-release review
Failures feed the readiness template; DORA measures update.
