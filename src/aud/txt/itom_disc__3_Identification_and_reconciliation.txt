Identification rules
How an incoming record is recognized as a CI we know. Independent classes match on their own attributes, dependent classes together with their host.
New rule
CLASS	IDENTIFIER ATTRIBUTES (TRIED IN ORDER)	KIND	PARTIAL PAYLOADS	WHY
Computer	serial_number name + ip_address	Independent	Held and retried	Physical and virtual servers: serial number first, then name together with IP.
Edit

Virtual machine	resource_id name + subscription_id	Independent	Rejected	Cloud virtual machines: the cloud resource ID never changes.
Edit

Network device	serial_number ip_address	Independent	Held and retried	Network gear: serial number, then management IP.
Edit

Endpoint device	serial_number	Independent	Rejected	Endpoints: Intune serial number.
Edit

Application	name + host (runs on)	Dependent	Held and retried	Dependent class: an application is identified together with the host it runs on, so two apps named Reader on different hosts stay separate.
Edit

Database	instance_name + host (runs on)	Dependent	Held and retried	Dependent class: a database instance is identified with its host.
Edit

Service	name	Independent	Rejected	Services are maintained by people; the name is the identity.
Edit

Rack	name + site	Independent	Rejected	Racks are identified by label inside a datacenter.
Edit
