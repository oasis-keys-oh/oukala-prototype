How clash detection works
The rule, in plain words

Hard clash: the release date sits inside a blackout freeze (or a restricted freeze for a major release), or another release or change touches the same service within 1 day. Soft clash: another release or change touches the same service within 3 days, touches a service this one depends on or supports within 1 day, or the same release manager has two windows on one day. Changes linked to the release are never counted against it.
